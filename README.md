# EmployeesManagement

EmployeesManagement is a simple .NET application for managing employee records.  
The repository contains source code that demonstrates basic CRUD operations, data storage, and application structure in C#.

## Overview

This project is intended for educational purposes and showcases:
- Working with employee data
- Interaction with a database
- Basic application architecture in .NET

## Technologies

- PostgeSQL
- EntityFramework Core
- ASP .Net Core 9
